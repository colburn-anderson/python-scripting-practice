# Python Scripting Practice

This repository contains focused Python scripting exercises designed to strengthen practical problem-solving skills and reinforce core programming fundamentals.

## Overview

The purpose of this repository is to build proficiency in:

- Regular expressions (regex)
- Text parsing and structured data extraction
- Log analysis and pattern detection
- Counting, aggregation, and validation logic
- Error handling and debugging
- Writing clean, maintainable Python code

Exercises emphasize understanding underlying logic rather than relying on prebuilt solutions.

## Example Areas of Practice

- Extracting structured fields from unstructured text
- Validating formatted identifiers (e.g., SKUs, emails)
- Parsing CSV-style inventory files
- Log file analysis (timestamps, IP addresses, error counts)
- Detecting malformed input and edge cases
- Building small command-line utilities

## Tech Stack

- Python 3
- Standard Library (`re`, `collections`, `sys`, etc.)
- No external dependencies

## Objective

To develop strong scripting fluency, improve debugging efficiency, and prepare for technical interviews that require practical text processing and analytical problem solving.
